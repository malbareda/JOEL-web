# 1.2. El paquet de projecte `dmoj/`

> Autor d'aquesta documentació: **Edgar**

Aquest és el paquet de configuració estàndard de Django (`dmoj/settings.py`, `dmoj/urls.py`,
`dmoj/celery.py`, `dmoj/wsgi.py`) —no s'ha de confondre amb el motor de jutge extern, que
malgrat compartir arrel de nom (`dmoj`) és un paquet Python completament separat, instal·lat en un
altre lloc del sistema (vegeu [2.7](../02-sistemes/2.7-jutge-intern.md)).

## `dmoj/settings.py`

El fitxer de configuració principal. Blocs destacats:

- **Configuració pròpia (`DMOJ_*`)**: identitat del lloc, interruptors de seguretat, ajust de
  puntuació de rendiment (`DMOJ_PP_STEP`, `DMOJ_PP_ENTRIES`, `DMOJ_PP_BONUS_FUNCTION`, detallats a
  [2.6](../02-sistemes/2.6-estadistiques.md)), límits de problema (temps/memòria mínims i màxims),
  comportament d'enviaments (límit de submissions, límit de *rejudge*), llindars d'estadístiques,
  configuració de 2FA/TOTP/codis de reserva, exportació de dades d'usuari, camins de memòria cau de
  PDF, i el mapa de colors dels resultats de submissió usat als gràfics.
- **Eines externes**: rutes a Node.js, ExifTool, i configuració de PhantomJS/SlimerJS/Puppeteer/
  Selenium per renderitzar enunciats en PDF, i de Mathoid/Texoid per renderitzar LaTeX.
- **`INSTALLED_APPS`**: inclou opcionalment `wpadmin` (un admin de Django amb un tema visual propi,
  amb un menú personalitzat organitzat per Problema/Submissió/Concurs/Usuari/Perfil/Navegació), més
  les apps estàndard de Django, `judge`, `registration` (alta/activació per correu),
  `mptt` (models en arbre, usats per comentaris i el menú de navegació), `reversion` (historial
  d'edicions), `social_django` (inici de sessió amb Google/Facebook/GitHub), `compressor`
  (empaquetat d'estàtics), `django_ace` (editor de codi), `pagedown` (editor Markdown antic, encara
  present junt amb el nou), `martor` (editor Markdown actual), `impersonate` (suplantació
  d'usuaris per a suport), `django_jinja`.
- **`MIDDLEWARE`**: una cadena personalitzada que inclou middleware propi per a *short-circuit*
  d'algunes vistes, autenticació d'API amb testimoni tipus *Bearer*, la lògica que assigna
  `request.profile` (i aplica els redireccionaments de 2FA/contrasenya compromesa), la lògica de
  suplantació, `request.participation`/`request.in_contest` per a concursos, registre d'últim accés,
  i activació del fus horari de l'usuari.
- **`TEMPLATES`**: els dos motors —Jinja2 per a gairebé tot, DTL per a l'admin i apps de tercers—
  descrits amb detall a [4](../04-particularitats-programacio/README.md).
- **`DATABASES`/`CACHES`/`LOGGING`/`CELERY_*`**: els valors base es deixen buits o mínims aquí, i
  s'omplen a `local_settings.py` (el fitxer específic de cada màquina, exclòs del control de
  versions).
- **Estils Markdown (`MARKDOWN_STYLES`)**: un perfil de sanejament/renderitzat diferent segons el
  context (comentari, enunciat de problema, entrada de blog, tiquet...), cadascun decidint si es fa
  servir el mode segur, si es proxegen imatges externes, i quines etiquetes HTML es permeten per a
  contingut escrit per professorat.
- **i18n**: la llista d'idiomes realment activats a la interfície (subconjunt dels presents a
  `locale/`), amb el català explícitament inclòs.
- **Autenticació**: la cadena d'`AUTHENTICATION_BACKENDS` prova primer Google/Facebook/GitHub
  (OAuth2) abans de recórrer a l'autenticació estàndard de Django.
- Al final, si existeix `local_settings.py`, s'executa i pot sobreescriure qualsevol valor anterior.

## `dmoj/local_settings.py`

Exclòs del control de versions (és específic de cada màquina). Aquí hi viuen, entre altres coses:
la clau secreta de Django, `DEBUG`/`ALLOWED_HOSTS`, les credencials reals de base de dades, la
configuració de memòria cau, els gestors de registre (*logging*), la configuració de correu
(incloent-hi els paràmetres de l'API de Gmail, vegeu més avall i
[5.7](../05-sistemes-mecanics/5.7-particularitats-servidor.md)), les URLs de Celery/Redis, la
configuració de connexió amb el dimoni d'esdeveniments en temps real, l'adreça del sòcol del pont
cap al jutge, i les rutes/URL d'actius estàtics.

## `dmoj/urls.py`

La configuració d'URL arrel, organitzada en blocs clarament delimitats: alta/inici de sessió,
llista/detall de problemes, "tasques" (agrupacions de problemes), gacha, l'arbre complet d'un
problema individual (detall, editorial, guia, PDF, enviament, gestió de dades de test...),
submissions, rànquings d'usuaris (incloent-hi les variants "primera"/"segona" pròpies d'aquest
fork), comentaris, concursos, organitzacions, estat de llenguatges/jutges, l'API (v1 i v2), blog,
la integració amb Mailgun per a rebots de correu, els diversos punts *widgets/* d'AJAX (incloent-hi
els de vista prèvia de Markdown i de pujada d'imatges de Martor), *feeds* RSS/Atom, i el sistema de
tiquets.

## `dmoj/celery.py`, `dmoj/wsgi.py`

Vegeu [5.1](../05-sistemes-mecanics/5.1-celery.md) per a Celery. `wsgi.py` és el punt d'entrada
WSGI estàndard, amb un pedaç perquè PyMySQL pugui substituir el controlador MySQLdb si aquest no
està instal·lat.

## `dmoj/gmail_api_backend.py`

Un backend de correu de Django personalitzat que envia correu a través de l'**API de Gmail** (amb
un compte de servei) en lloc de per SMTP directe —detallat a
[5.7](../05-sistemes-mecanics/5.7-particularitats-servidor.md).
