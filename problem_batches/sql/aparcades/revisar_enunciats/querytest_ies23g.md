## IES23 QT — Subconsultes amb EXISTS, ANY i ALL
- L'enunciat original parlava d'«alumnes» i de tasques «associades a la seva unitat formativa», però el SQL no filtra per rol ni comprova la unitat formativa; s'ha ajustat el text al SQL. Enunciat generat: Mostra el nom (`nomUsuari`) i els dos cognoms en una sola columna separats per un espai (`cognoms`, a partir de `cognom1Usuari` i `cognom2Usuari`) dels usuaris (`usuaris`) que tenen almenys una tasca assignada a `tasques_alumnes` que correspongui a una tasca existent de `tasques`. Fes-ho amb EXISTS.
- L'original deia «alumnes», però el SQL no filtra per `rol` i retorna també professors i altres usuaris; s'ha ajustat el text al SQL. Enunciat generat: Mostra el nom (`nomUsuari`) i els dos cognoms en una sola columna separats per un espai (`cognoms`, a partir de `cognom1Usuari` i `cognom2Usuari`) dels usuaris (`usuaris`), de qualsevol rol, que no tenen cap tasca a `tasques_alumnes`. Fes-ho amb NOT EXISTS.
- S'ha tret el «per exemple» de l'original: el SQL fixa `idmodul` = 3. Enunciat generat: Mostra l'`id`, la unitat (`unitat`) i les hores (`hores`) de les unitats formatives (`unitats_formatives`) que tenen més hores que totes les unitats formatives del mòdul amb `idmodul` igual a 3. Fes-ho amb ALL.
- Columnes i àlies precisats a partir del SQL (l'original només deia «nom i cognoms»). Enunciat generat: Mostra el nom (`nomUsuari`) i els dos cognoms en una sola columna separats per un espai (`cognoms`) dels usuaris (`usuaris`) que tenen alguna nota (`nota`) superior a 8 en algun mòdul (taula `alumnes_moduls`). Fes-ho amb EXISTS.
